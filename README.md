# post-site-closure

A planned OpenClaw + Telegram assistant for timed site check-ins and review-ready CRM notes.

> [!NOTE]
> This repository is at the concept stage. The implementation has not been published yet.

## Intended flow

1. Start a site job.
2. Receive timely check-in prompts.
3. Reply with only the details still needed.
4. Generate a concise, CRM-ready draft.
5. Review the note before entering it in the CRM.

The goal is a low-friction workflow that asks technicians fewer questions while keeping a person in control of the final record.
